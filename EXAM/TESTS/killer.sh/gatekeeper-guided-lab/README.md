# Gatekeeper Guided Rego Lab

Percorso guidato per imparare a leggere e modificare ConstraintTemplate,
Constraint e regole Rego.

## Avvio

```bash
chmod +x setup-gatekeeper-guided-lab.sh
./setup-gatekeeper-guided-lab.sh
```

Le lezioni vengono create in `~/course-gatekeeper-guided`. Ogni lezione
contiene spiegazione, esempio funzionante, starter con TODO e workload di test.

Procedi in ordine: schema, input, parametri, collezioni, match, UPDATE,
inventory, audit e troubleshooting.
