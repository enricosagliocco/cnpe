# Kyverno Guided Policy Lab

Percorso guidato per imparare a leggere, copiare e modificare policy Kyverno
CEL `policies.kyverno.io/v1`.

## Avvio

```bash
chmod +x setup-kyverno-guided-lab.sh
./setup-kyverno-guided-lab.sh
```

Le lezioni vengono create in `~/course-kyverno-guided`. Ogni directory
contiene:

- `README.md`: spiegazione della sintassi e modifica guidata;
- `example.yaml`: esempio funzionante da leggere;
- `policy.yaml`: starter da completare;
- `bad.yaml` e `good.yaml`: test.

Procedi in ordine: ogni lezione introduce un solo costrutto nuovo.
